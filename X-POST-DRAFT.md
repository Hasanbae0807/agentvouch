# X POST DRAFTS — Community Promotion (DRAF SAJA, JANGAN DIPOSTING OTOMATIS)

Untuk jalur Community Promotion (2.000 USDC / 20 pemenang): posting dari akun
X tuan (@Acokletik), lalu kirim link postingan lewat survey resmi di
app.binance.com. Kedua draf berisi hashtag wajib #BinanceWalletHackathon dan
#AgenticWallet + link repo. Tanpa janji imbal hasil, tanpa klaim afiliasi
dengan Binance/BNB Chain.

## Draf 1

> Agent ID gives your agent a name. AgentVouch gives it a reputation.
>
> Holders endorse each other for skills — fully on-chain, keyed by handles the
> contract resolves itself from the Agent ID registry, so identity can't be
> faked. No funds, no approvals — endorsements only.
>
> Try it: https://github.com/Hasanbae0807/agentvouch
>
> #BinanceWalletHackathon #AgenticWallet

## Draf 2

> Built for the Agent ID Hackathon: AgentVouch — a trust graph for the agent
